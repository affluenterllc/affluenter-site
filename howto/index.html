How do I…?

Short answers for Affluenter Vault on Android. New to the app? Start with the guide.

Copy a password without opening the item

  1. On the Vault tab, find the item (search or scroll).
  2. Press and hold the item.
  3. Tap Copy username, Copy Password or Copy 2FA code, then paste it where you need it.

Passwords and codes are cleared from the clipboard after 30 seconds (you can change this in Settings).

Turn on autofill

  1. After you unlock, the app asks “Make Affluenter Vault your password manager?” — tap Yes.
  2. Confirm Affluenter Vault on your phone’s screen.
  3. Tap “Open Chrome setting” and choose “Autofill using another service”, then restart Chrome.
  4. Check it in More → Settings → Autofill: both should show as set.

Android always asks you to confirm; no app can switch this by itself. Chrome needs Android 14 or later.

Autofill isn’t showing up

  1. Check More → Settings → Autofill shows Affluenter Vault as the service (and Chrome set to “another service”).
  2. Tap the username or password box again; some apps only ask when a box is tapped.
  3. Look just above the keyboard: some keyboards show suggestions there as chips.
  4. If you see 🔒, tap it and unlock.
  5. Still nothing? In Android Settings set the autofill service to “None”, then back to Affluenter Vault.

Some banking apps block autofill. Hold the item in the vault and copy the password instead.

Save a new login

  1. With autofill on, sign in to the app or website as usual.
  2. When Android asks “Save to Affluenter Vault?”, tap Save.
  3. A short message confirms it, with Undo and Edit.

If the login already exists, its password is updated and the old one is kept in Previous values.

Create a strong password when signing up

  1. On the sign-up form, tap the password box.
  2. Tap “🔑 Create a strong password” in the suggestions.
  3. The password is saved in the vault first, then filled in. Finish signing up.

On a change-password form, the new password waits until you confirm the site accepted it.

Add an item or a field

  1. On the Vault tab, tap ＋ (bottom right) and choose a type, such as Login or Credit Card.
  2. Fill in the boxes and tap Save.
  3. To add more, open the item → Edit → Add field: pick the type first, then type the value.
  4. Use ↑ ↓ to change the order of the fields.

Grey text in an empty box is only an example. Empty fields don’t show on the item.

Add a 2FA code

  1. On the website, start setting up 2-step verification until it shows a QR code.
  2. In the vault, open that site’s login → Edit → Add field → 2FA code.
  3. Tap 📷 and scan the QR code (or paste the setup key), then Save.
  4. Type the 6-digit code the item now shows into the website to finish.

All codes are on the 2FA codes tab. Tap a code to copy it. Codes also fill the code box automatically.

Move 2FA codes from Google Authenticator

  1. In Google Authenticator: open the menu → Transfer accounts → Export accounts, and choose the accounts.
  2. In Affluenter Vault: More → Import 2FA codes.
  3. Scan the QR code(s) Google Authenticator shows.
  4. Check the codes on the 2FA codes tab before deleting anything from the other app.

Microsoft Authenticator can’t export its codes, so add those again from each site.

Import passwords from Google, Samsung or another app

  1. Export your passwords from the other app (Google: Chrome → Settings → Password Manager → ⚙ Settings → Export passwords).
  2. In Affluenter Vault: More → Import and pick the file.
  3. When it’s done, delete the exported file — it isn’t encrypted.
  4. Then open the Security tab to merge any duplicates.

On Android 14 and later, some managers can move logins and passkeys straight across with no file.

Back up your vault

  1. More → Settings → Backup, sync & import → Save an encrypted backup now.
  2. Save it somewhere off the phone, such as Google Drive.
  3. Optional: turn on Daily copies to keep one copy per day for 7 days.

Backups stay encrypted with the master password you had when you made them. Never uninstall the app to fix a problem.

Undo a restore or import

  1. More → Settings → Backup, sync & import.
  2. Tap Undo last restore.
  3. Your vault goes back to how it was before the last restore or import.

To add a backup’s missing items without replacing your vault, use Merge a backup instead of Restore.

Move to a new phone

  1. On the old phone, save an encrypted backup to Google Drive (see “Back up your vault”).
  2. On the new phone, install Affluenter Vault and tap “Restore from an Affluenter Vault backup”.
  3. Pick the backup and enter the master password it was made with.
  4. Turn on fingerprint unlock and autofill again.

Pro users can also sync both phones through Google Drive.

Unlock with fingerprint or PIN

  1. More → Settings → Security.
  2. Turn on fingerprint unlock, or tap Unlock with PIN and choose 6–8 digits.
  3. Choose how soon the vault locks itself (Auto-lock).

You still need your master password for backups and on a new phone, so don’t forget it.

Fix weak, reused and old passwords

  1. Open the Security tab.
  2. Work through the steps from the top; each one shows what it will change.
  3. For a weak or breached password, tap Fix: the app makes a new one and opens the site’s change-password page.
  4. Change it on the site, then tap Done (or Didn’t work).

Nothing changes until you tap a button, and most steps have Undo.

Merge duplicate logins

  1. Open the Security tab (step 1) or More → Find duplicates.
  2. Open a set and choose which copy to keep.
  3. Tap Merge: other passwords go into Previous values, the copies go to Recently deleted.

Undo puts everything back.

Scan a card and fill it at checkout (Pro)

  1. Tap ＋ → Credit Card, then 📷 to scan the front (and back) of the card.
  2. Check the details and Save.
  3. At checkout, tap the card number box and pick the card; confirm with your fingerprint.

Suggestions never show the full number — only •••• 1234.

Keep IDs and documents in Secure Files

  1. Tap the 📁 Files chip on the Vault tab (or More → Secure Files).
  2. Tap Scan a document, Take a photo or Choose files.
  3. Pick a folder. Hold a folder to rename or delete it.

Files are encrypted and never added to your gallery. Free: up to 10 files; Pro: unlimited.

Switch to dark or light mode

  1. More → Settings → Appearance.
  2. Choose System default, Light or Dark.

It changes right away on every screen.

Forgot your master password

  1. If fingerprint or PIN unlock still works, open the vault that way and save a fresh backup or emergency backup.
  2. Nobody — including Affluenter — can reset the master password.
  3. Plan ahead: More → Settings → Emergency access makes a printable Emergency Kit.

This is what keeps your vault safe if the phone is lost.
