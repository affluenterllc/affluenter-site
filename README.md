# affluenter.com

Static site for Affluenter Vault, served by GitHub Pages at https://affluenter.com.

The pages are edited directly. There is no site generator: `make_site.py` has never existed in
`affluenter-vault` or in this repo. The Privacy Policy and Terms should still match the app's own copies word for word.

The HOA pages (`/hoa/`) are the exception. They are built by `website/make_hoa_pages.py` in
`affluenter-hoa`, which writes into a checkout of this repo. Regenerate them there and copy the output here.
